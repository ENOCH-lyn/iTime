# iTime 文档索引

更新：2026-10-09。当前需求版本为 `0.2`；已进入完整 Web 首版开发。Chat-first 全站信息架构、GPT 式 AI 对话、安全 Markdown、统一设置、Element Plus 控件边界和精简文案已实现，并完成 Chromium 全量、真实 Edge 关键路径及逐张截图审查；AI Agent 自动意图和图片/网页/文字统一课表导入已有实现证据。此前完成范围和真实验证状态见[实施与验证](验收/iTime-Web实施与验证.md)；M8-B 备份恢复、M8-C 生产发布、系统化正式模型质量和实体设备仍未完成，产品尚未部署。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已确认 | 用户明确的产品或技术约束 |
| 建议 | 工程或交互方案，不能冒充用户确认或实测结论 |
| 待确认 | 影响产品行为的未定规则，实施前需明确 |
| 待配置 | 需真实资源或运营参数才能填入的配置 |
| 后续阶段 | 已分期能力，如 Android、iOS 和 App 提醒 |
| 未实现/未执行 | 尚无真实业务实现或对应测试证据 |
