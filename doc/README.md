## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已确认 | 用户明确的产品或技术约束 |
| 建议 | 工程或交互方案，不能冒充用户确认或实测结论 |
| 待确认 | 影响产品行为的未定规则，实施前需明确 |
| 待配置 | 需真实资源或运营参数才能填入的配置 |
| 后续阶段 | 已分期能力，如 Android、iOS 和 App 提醒 |
| 未实现/未执行 | 尚无真实业务实现或对应测试证据 |

## 更新规则

需求变化同步规格、追踪、受影响设计、用例与计划。文档只保留 iTime 的有效内容；不保存无关参考资料、认证过程或工具测试记录。已有明确结论不重复访谈，实际实现和验证结果按发生情况补充。
