## 2. App 后续准入

Android、iOS 分阶段记录完整功能对等、真机 UI、后台/锁屏/重启、离线同步、提醒及系统权限、签名/分发和 API 兼容证据。App 尚未实现，不以 Web 回归替代真机结果。

## 3. 真实验收记录要求

实际执行后按版本记录：提交 SHA、环境/设备、数据集、用例/步骤、预期、实际、结论、失败原因及证据位置。通过、失败、阻塞、未执行分别填写。

存在数据丢失、越权、平台 Key 泄露、重复扣额、未确认 AI 写入、固定约束破坏或核心流程不可用时阻断交付。其他遗留项需写清影响和处理方式，不使用“基本完成”代替范围说明。
