# iTime AI 课表统一导入设计

版本：0.1；更新：2026-10-08。本文定义从 AI 会话和统一日历进入同一课表导入流程，支持图片、公开网页、文件和文字描述，并在用户校对确认后写入日历。

## 1. 目标与入口

课表导入提供两个等价入口：

- AI 会话：发送图片、文件、网址或文字，例如“每周一三 8:00 上高数，持续到 1 月 10 日”。
- 日历页面：点击“导入”，在同一弹层选择图片、文件、网址或文字。

两个入口调用同一服务、生成同一种导入批次和候选，使用同一个候选编辑器。未经确认的候选不进入正式日历。

## 2. 支持来源

| 来源 | 处理方式 |
| --- | --- |
| 图片 | 复用现有截图临时媒体与视觉识别能力 |
| XLSX / ICS 文件 | 复用现有确定性解析器 |
| 公开网页 URL | 受限抓取后识别日程内容；ICS 地址优先走确定性解析 |
| 文字描述 | AI 提取课程、日期范围、星期、时间、地点和重复规则 |

公开网页不携带浏览器 Cookie、账号凭据或系统代理，不支持需要登录的页面。抓取沿用现有 SSRF、防重定向绕过、大小、类型、超时和私网限制；网页正文是不可信输入，不得覆盖系统指令或扩大工具权限。

## 3. 统一数据流

1. 客户端创建导入请求，提交来源类型、来源内容、用户时区和可选学期上下文。
2. 服务端校验输入并创建持久化导入批次。
3. 文件使用确定性解析；图片、网页正文和自然语言使用 AI 导入能力。
4. AI 或解析器输出进入统一规范化和业务校验。
5. 服务端创建 `CalendarImportCandidate` 候选，标记有效、需补充、重复或无效。
6. 会话中显示候选摘要；日历弹层展示完整可编辑列表。
7. 用户修改、选择、跳过并确认。
8. 服务端重新校验候选版本，在一个事务中创建正式日历系列和同步事件。

关闭页面或弹层不取消后台识别。重新进入后可通过批次 ID 恢复排队、识别、校对或终态结果。

## 4. 导入批次

现有 `CalendarImportBatch` 扩展来源语义，区分：

- `xlsx_file`
- `ics_file`
- `image`
- `public_url`
- `text`

批次保存来源类型、状态、版本、输入摘要、临时媒体引用、来源显示地址、关联会话与消息、作业 ID 和过期信息。原始图片按现有规则在确认后或最迟 24 小时清理；网页正文和 AI 技术正文按 7 天规则清理；正式日历只保留用户确认后的结构化字段和必要来源摘要。

批次状态统一为：

- `queued`
- `processing`
- `needs_review`
- `confirmed`
- `cancelled`
- `failed`
- `expired`

## 5. AI 输出与校验

AI 使用独立类型化工具输出，不把模型正文直接转成正式日历。每个候选最多包含：

- 课程或安排名称
- 可选说明和地点
- 起止日期或学期周次
- 星期、开始和结束时间
- 时区
- 重复规则和例外
- 识别置信度
- 无法确定的字段
- 对应原文片段

服务端校验：

- 名称、时间、日期、时区和重复规则格式。
- 结束晚于开始，跨午夜必须明确。
- 日期范围和展开数量有界。
- 学期、节次和周次引用属于本人。
- 同一批次的语义重复和既有日历重复。
- 夏令时缺失或重复时刻不静默调整。
- AI 不能创建未知业务 ID，也不能把网页指令当作操作命令。

缺少日期范围、时区或无法唯一确定节次时，候选进入“需补充”，不静默猜测。

## 6. 会话体验

会话输入框提供附件菜单，但不要求用户先选择“课表模式”：

- 上传图片或文件后可补充一句说明再发送。
- 粘贴 URL 后 Agent 自动判断为公开网页、ICS 或普通文本链接。
- 纯文字描述直接触发课表导入提案。

识别中显示真实状态；完成后消息流展示课程数量、需补充数量、重复数量和日期范围。用户可以：

- “确认导入”直接确认全部有效候选。
- “调整”打开统一候选编辑器。
- “取消”取消未确认批次。

确认后消息卡显示实际新增和跳过数量，并提供“在日历中查看”。

## 7. 日历体验

日历的“导入”弹层使用 Element Plus：

- 顶部以 `ElTabs` 或 `ElSegmented` 切换图片、文件、网址和文字。
- 图片/文件使用 `ElUpload`。
- 网址与文字使用明确输入框和一个主要提交按钮。
- 处理中显示真实阶段和取消命令。
- 候选使用同一列表编辑器，宽屏为紧凑列表，窄屏为单列全屏抽屉。
- 底部只保留“确认导入”和“取消”；终态批次不展示写操作。

界面不重复介绍 AI 能力，不显示“智能识别”等营销文案；标题、来源、状态和操作足够表达当前任务。

## 8. 幂等、冲突与恢复

- 创建批次、编辑候选、取消和确认都使用 `operation_id`。
- 同一操作号与相同输入返回原结果，不重复创建批次或日历系列。
- 候选编辑要求批次和候选版本；冲突时保留当前填写并展示服务器最新值。
- 确认事务重新读取所有候选和重复身份，避免多端重复导入。
- AI 失败或取消不扣用户额度；有效候选可查看时结算。
- 确认失败不会产生部分日历系列，原批次仍可恢复和重试。

## 9. 验收

至少验证：

- 会话发送课表图片，生成候选，修改一项后确认并出现在日历。
- 会话发送自然语言课表，无模式切换即可生成候选。
- 日历入口分别处理图片、XLSX、ICS、公开网页和文字。
- URL 重定向私网、超大响应、非支持类型、超时和恶意网页指令均被拒绝。
- 缺字段、重复课程、跨午夜、DST、学期周次和版本冲突。
- 刷新、离页、worker 重启和响应未知后恢复同一批次。
- DeepSeek 真实图片和文字识别；公开网页使用本地受控 HTTP 站点验证抓取边界。
- Chromium 与真实 Edge 的电脑、平板、手机视口、键盘、上传和候选编辑。
