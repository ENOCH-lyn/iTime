# iTime 任务生命周期设计

更新：2026-10-03。本设计在现行需求“完成后不自动归档”和“单项删除进入 30 天回收站”之上，定义首版任务归档、恢复与到期清理合同。关联计划、报告、困难、AI 日志和质检样本尚未实现；它们接入时仍须按 Q-DATA-01 / Q-PRIV-01 补充跨聚合清理规则。下述细节是可演进工程默认，不冒充用户已确认的产品决定。

## 1. 方案与边界

采用任务主表生命周期时间戳加最小墓碑：

- `archived_at` 与完成状态正交。未完成和已完成任务都可手动归档；完成不会自动归档。
- `deleted_at` 表示进入回收站，`purge_after` 固定为删除事务时间后 30×24 小时；数据保留期限不使用活动日或用户时区，也不因用户修改时区而重算。
- 回收站期间保留任务、步骤、链接、标签、截止/重复规则和实例状态。任务只读，只允许恢复。
- 删除保留原 `archived_at`。恢复清除 `deleted_at` 与 `purge_after`，使任务回到删除前的活动或归档范围。
- 到期清理删除任务正文及直接关联明细，保留任务 ID、所有者、删除时间、清理时间和递增版本形成墓碑。墓碑阻止旧设备、旧操作或在途作业重新创建同一业务对象。

未采用单独回收站快照表，因为它会复制完整任务聚合并增加恢复一致性成本；未采用直接物理删除加独立删除台账，因为任务重复系列存在前序外键，且首版同步仍需稳定墓碑。

## 2. 状态与可见性

任务生命周期按以下优先级派生：

| 状态 | 条件 | 可见范围 | 允许动作 |
| --- | --- | --- | --- |
| `active` | 无归档、删除、清理时间 | 默认任务列表、项目/标签计数、日历投影 | 查看、编辑、完成、日期/实例操作、归档、删除 |
| `archived` | 有归档时间，无删除/清理时间 | 已归档列表 | 查看、取消归档、删除 |
| `trashed` | 有删除时间，无清理时间 | 回收站 | 查看、恢复 |
| `purged` | 有清理时间 | 不进入任何列表 | 不能恢复或编辑；按本人 ID 访问返回已过恢复期 |

普通任务、项目计数、标签计数和日历 occurrence 查询只包含 `active`。归档或删除不会改写任务完成状态和实例历史。回收站清理不删除被后继重复任务引用的任务墓碑。

## 3. API 与并发

- `GET /api/v1/tasks?lifecycle=active|archived|trashed`：默认 `active`，其余筛选与游标在所选范围内继续生效。
- `PUT /api/v1/tasks/{id}/archive`：提交 `operation_id`、`expected_version` 和 `archived`。
- `DELETE /api/v1/tasks/{id}`：提交 `operation_id` 和 `expected_version`，进入回收站。
- `POST /api/v1/tasks/{id}/restore`：提交 `operation_id` 和 `expected_version`，恢复删除前范围。

生命周期写入沿用账号级写锁、任务行锁、乐观版本和操作幂等。实际变化递增任务版本、更新时间并写入变更事件；同状态请求不增版。普通编辑或日期/实例写入遇到归档、回收站或墓碑任务时返回可恢复的冲突，不自动取消归档或恢复。版本冲突不覆盖新状态。

删除响应返回 `purge_after` 和剩余天数。服务端时间是保留期限的唯一依据；界面显示值只用于说明，不参与清理判断。

## 4. 到期清理

独立任务清理进程按 `purge_after, id` 有界领取最多 100 条到期记录，并使用 PostgreSQL `FOR UPDATE SKIP LOCKED` 支持多进程安全并行。每条任务在一个事务内：

1. 删除步骤、链接、标签关联、日期/重复规则和实例状态；
2. 删除响应中包含该任务 ID 的幂等操作缓存，避免清理后重放返回旧正文；
3. 清空标题、正文、项目、估时、优先级和完成事实；
4. 设置 `purged_at`、递增版本并写入 `purged` 变更事件。

重复执行只处理尚未清理的到期记录。进程失败由事务回滚，下一轮可继续。首版通过 `python -m itime.tasks.cleanup_worker` 常驻运行，也支持 `--once` 供定时任务和测试执行。

## 5. 失败恢复与验证

- 归档/删除/恢复响应丢失：使用相同 `operation_id` 重试，返回原结果且不重复增版。
- 陈旧页面操作：返回当前版本；界面刷新后显示真实生命周期，不把本地草稿自动覆盖到墓碑。
- 回收站过期：返回不可恢复状态，并提供请求编号；不会以新建同 ID 的方式恢复。
- 清理进程中断：已提交任务保持墓碑，未提交任务保持完整回收站数据。
