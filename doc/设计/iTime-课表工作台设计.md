# iTime 课表工作台设计

版本：0.1；更新：2026-10-20。本文记录 2026-10-20 用户对前端体验的重构要求与首版实现：以课表为首页，任务围绕课表，AI 作为统一入口。

## 1. 背景与目标

用户明确反馈现前端不好用，要求：

1. 首先是一个合理的课表应用，功能参考常用课表软件；
2. 是时间管理软件，可以创建任务并设置周期；
3. AI 为主力，尽量让 AI 操作功能，减少手动设置；
4. 不再围绕旧 PRD 的边界情况堆叠交互，优先用户体验；UI 与交互可以重写。

首版目标是让用户打开应用就能看到本周课表，顺手加任务，并把复杂安排交给 AI，而不是先进入一个对话空页。旧的 Chat-first 单栏结构保留在 `/ai`，作为完整对话与导入入口。

## 2. 信息架构

- 登录、注册、邮箱验证完成后默认进入 `/timetable`。
- 顶部导航：课表、任务、AI、复盘；右侧是周切换、今天、添加课程、AI 和账号。
- 主区域三列：
  - 左：今天的任务（逾期、今天、本周、更晚/无日期），支持快速添加、勾选完成、打开完整任务页；
  - 中：本周课表（按分钟定位，支持周切换、学期周次、点击空白新建、点击课程查看详情）；
  - 右：AI 助手（建议问题、自然语言输入、进入完整对话）。
- 窄屏：三列纵向堆叠，课表横向滚动；AI 与任务位于课表下方，避免隐藏入口。

## 3. 课表

- 以周一为一周起点，显示 7 天；当前天高亮。
- 有学期时按 `first_week_monday` 计算第几周；周次可直接下拉跳转，也可上一周/下一周。
- 时间轴按真实分钟定位，不采用等高格；小时线每小时一条，当前时间用红线标出。
- 学期配置了节次时，时间轴改为“第 N 节 + 开始时间”，并按节次开始位置绘制横线；没有节次时退回小时刻度。
- 事件块按开始/结束时间定位，重叠事件自动分栏；短事件有最小高度，超出两行的标题省略。
- 时间范围根据学期节次、当天课程与当日任务动态计算，默认 08:00–18:00，最早/最晚自动扩展，避免固定 24 小时的空白。
- 已确认的日/周计划块也显示在课表上，使用“计划”样式，与课程同轴定位。
- 课程颜色由名称稳定映射到六色调色板；取消的事件降低对比度。
- 点击空白时间块：按 15 分钟吸附，打开“添加课程或安排”，预填日期与时间。
- 点击事件块：右侧抽屉显示名称、时间、地点，并提供编辑、删除；订阅事件与任务事件按来源限制可编辑性。
- 新建课程要求先有学期：按学期首周与结束日期生成有效周次；固定安排可选择每周重复或仅一次。
- 课程新建/编辑可选择开始周与结束周（例如第 3–5 周），只在这些周出现；开始日期由起始周、所选星期和学期首周自动计算。
- 新用户没有学期时，课表上方显示“先设置学期”引导，可直接打开“时间与学期”对话框；未设置学期时点击添加课程会先引导设置，而不是报错。

## 4. 任务

- 左侧任务面板只显示当前未完成任务，按截止日期分组；无截止日期的进入“更晚 / 无日期”。
- AI 计划块对应的任务按计划日期归入“本周”，并显示“排期 10/22”等标记，避免同一条安排同时出现在课表和“无日期”里。
- 快速添加：回车创建，默认截止今天；失败时在顶部提示，不丢失输入。
- “更多选项”支持标题、日期、重复方式（不重复 / 每天 / 每个工作日 / 每周 / 每月 / 每年）、重复结束日期与预计用时。
- 点击任务标题打开详情抽屉：显示截止、重复（含结束日期）与预计用时，可直接完成、编辑、推迟到明天（仅不重复任务）、打开任务页或移入回收站。
- `/tasks` 现在是新的任务工作台：今天/本周/全部/已完成筛选、搜索、快速添加、周期编辑与详情抽屉；`/tasks/full` 保留步骤、标签、项目、回收站和语音等高级管理。
- 编辑任务会保留原有重复结束条件（`until` 或 `count`），修改重复方式时按表单日期重建月/年规则，避免丢失结束条件。

## 5. AI 入口

- 右侧 AI 面板提供四个高频示例：排作业、每周固定课程、明天开会、复盘今天。
- 提交后不跳页：服务端创建/复用会话并发送消息，前端轮询 AI 作业，面板显示“正在读取课表并生成安排”。
- **任务安排**：AI 调用既有 `propose_itime_task_plan` 工具，面板内渲染 `AgentProposalMessageCard`。用户点“确认添加”后调用 apply，当前事务创建任务与计划块；计划块以“计划”样式出现在课表，任务按排期归入“本周”。
- **周期性课表**：AI 调用既有 `propose_itime_timetable_import` 工具，创建课表导入批次；面板显示“查看并确认课表导入”，弹窗内复用 `TimetableImportMessageCard` 校对候选并确认，写入日历系列。
- **任务修改/完成**：AI 调用 `propose_itime_task_update` 或 `propose_itime_task_complete`，面板内渲染 `TaskActionProposalCard`；确认后调用 `/api/v1/ai/tool-proposals/{id}/apply`，由任务服务校验所有权、可编辑性和版本，再更新标题/描述/估时/优先级/截止日期或标记完成；重复任务必须指定 occurrence，当前会拒绝整条完成。AI 修改日期只支持非重复任务，重复规则本身仍由任务页编辑。
- **任务删除**：AI 调用 `propose_itime_task_delete`，卡片显示“删除任务”，确认后按任务回收站语义写入 `deleted_at` 与 30 天清理时间，并停止公开链接抓取；确认前不改变数据。
- 纯文本回复直接显示在面板内；保留“在完整对话中继续”链接，进入 `/ai` 查看完整会话。
- 所有写入都必须先预览、后确认；与固定课程冲突时服务端拒绝应用，错误显示在卡片内（例如 15 分钟缓冲不足的 `plan_fixed_conflict`）。
- 当前接入的是对话 Agent 的五项工具（任务计划、课表导入、任务更新、任务完成、任务删除）；`ai/tools` 中面向规划/复盘/记忆的通用写预览工具仍属于 S2-D3，尚未接入。

## 6. 视觉

- 沿用工作区已有的浅灰绿画布与绿色主色，但提高留白、圆角与字号层级；AI 面板使用深绿色实底，作为唯一强对比区域。
- 不使用装饰插画、渐变堆叠或虚构数据；所有课程、任务来自真实接口。
- 事件块颜色只承担区分作用，文字始终使用正文色，保证明暗主题可读。
- 主要操作高度不低于 38–44px；移动端课表可横向滚动，并提示“左右滑动查看周末”。
