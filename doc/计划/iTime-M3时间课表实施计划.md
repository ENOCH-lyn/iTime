## 1. 提交边界

每项完成代码、迁移、测试和文档后独立提交：

1. **时间设置与学期节次服务**
   - 为用户保存 IANA 时区、周起点和 04:00 活动日边界。
   - 学期增改查、完整节次表原子替换、版本和操作幂等。
   - 验证无效时区、日期范围、节次重叠、所有权、并发和迁移回退。
2. **固定安排、重复系列与例外服务**
   - 课程/固定安排系列、结构化重复规则、单次取消/移动/覆盖及独立关联补课。
   - 93 天有界 occurrence 展开、夏令时异常、跨午夜和重叠冲突返回。
   - 验证单双周、指定周、月末、闰年、系列分割、双设备版本竞争。
3. **任务日期、重复与拆分服务**
   - 日期型/定时截止、重复模板和实例、15 分钟默认最小连续时长、可拆属性。
   - 本次/未来/全部修改，跳过与补做；任务完成仍由用户确认。
4. **课表和日历 Web 页面**
   - 学期与节次设置、手工课程/固定安排、周/月视图和例外编辑。
   - 桌面、平板、手机真实 UI 测试，包含冲突、跨日和夏令时错误。
5. **Excel 与 ICS 文件导入**
   - 模板下载、严格解析、候选校对、部分确认、重复与冲突提示。
   - 使用真实文件和破损文件验证，不用静态样例替代。
6. **截图识别和 ICS 订阅**
   - 复用持久化作业、受限外部访问和 AI 配置；实现确认后/24 小时媒体清理。
   - 订阅刷新、来源取消、本地例外及计划冲突标记。

## 2. 第一提交实现细目

数据库：

- `user_time_settings`：用户唯一设置、IANA 时区、周起点、活动日分钟、版本。
- `academic_terms`：账号隔离的学期、日期范围、第一周周一、时区和版本。
- `term_periods`：学期内节次、名称、本地起止时刻；复合所有权外键和唯一约束。
- 迁移 `0006_time_settings_terms` 可从 head 升级、回退并通过 Alembic 模型一致性检查。

API：

- `GET /api/v1/time-settings` 在无记录时返回 `initialized=false`，不把服务端 UTC 冒充用户时区。
- `PUT /api/v1/time-settings` 校验 IANA 时区，使用版本和 `operation_id`。
- `POST/GET/PUT /api/v1/terms` 支持稳定分页、本人隔离和版本冲突。
- `PUT /api/v1/terms/{id}/periods` 以完整列表原子替换，拒绝重复编号、重复名称、逆序及重叠区间。

失败与恢复：

- 所有写操作与 `change_events` 同事务；同一操作可安全重放。
- 他人资源与不存在资源统一 404。
- 版本冲突返回当前版本；数据库错误保持 `saved=unknown`。
- 时区、日期和节次输入错误不回显敏感请求正文。

验证：

- 真实 PostgreSQL/HTTP 集成测试，不使用 SQLite 或 mock 仓储替代。
- 至少覆盖首次读取、有效/无效时区、03:59/04:00 活动日、学期边界、节次相邻与重叠、幂等、版本冲突、跨账号访问和并发写入。
- 执行 Ruff、专项测试、服务端全量测试、迁移升降级、`alembic check` 和构建。
